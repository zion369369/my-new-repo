# Contributing to this Project

Thanks for your interest in contributing! 🎉 All contributions are welcome and appreciated.

---

## How to Contribute

1. **Fork** the repository and create your branch from `main`.
2. Make your changes — keep them focused and easy to review.
3. **Test** your changes to make sure everything works as expected.
4. Open a **Pull Request** with a clear description of what you changed and why.

---

## Reporting Issues

Found a bug or have a feature request? Please [open an issue](../../issues/new) and include:

- A clear and descriptive title.
- Steps to reproduce the problem (for bugs).
- What you expected to happen vs. what actually happened.
- Any relevant screenshots or error messages.

The more detail you provide, the easier it is to help! 🙏

---

## Submitting Pull Requests

- Keep pull requests small and focused on a single change.
- Write a clear PR title and description explaining your changes.
- Reference any related issues using `Closes #issue-number` in the description.
- Be patient and open to feedback — reviews are meant to help, not criticize.

---

We're glad you're here. Happy contributing! 🚀
